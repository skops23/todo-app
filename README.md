# Mis tareas

App de Expo y React Native para agregar, editar, completar y eliminar tareas. Las tareas se guardan en el dispositivo con AsyncStorage. La app toma el tema del sistema al abrir y permite cambiarlo desde la lista.

## Ejecutar la app

```sh
npm ci
npx expo start
```

En la terminal de Expo, presiona `w` para probar en el navegador o `a` para abrir el emulador de Android. También puedes escanear el código QR con una instalación compatible de Expo Go.

Para editar una tarea, toca el lápiz y guarda el nuevo título. Toca el círculo para cambiar su estado y la papelera para eliminarla.
